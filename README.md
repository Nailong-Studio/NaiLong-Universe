## 二、本馆是什么

奶蛙，是官方奶龙角色的民间 AI 变异体。其体貌特征经本馆学术委员会核定如下：黄色、圆润、浅米色腹部、绿色眼圈、灰褐色小爪。五项缺一不可，参观时不设安检，但请自行确认。

本馆将奶蛙安置进西方美术史的展厅：维纳斯换成奶蛙，大天使长的审判换成奶蛙，星月夜与呐喊也一并移交。四百年的庄严被同一只蛙反复签收，学界至今没有给出合理解释。

你可以把这里理解为一座美术馆。区别在于，这里的每幅画都在笑，而且笑得很讲礼貌——它们不会在你靠近时突然停止。

## 四、参观动线（经消防演练）

- **入殿**：画廊双开金门 → 常设展厅横向巡游 → 单厅前言墙 → 沉浸放映厅。逐层递进，不会一步把你传送到付款页面。
- **说明牌**：桌面左图右牌，移动上下堆叠；编号、形制、原作与叙事一应俱全。
- **可分享的每一层**：单厅、单件作品均可直接转发定位，适合在群里精准投放一只蛙。
- **馆藏检索**：关键词 + 分厅筛选，命中即直达说明牌。
- **艺术史长河**：从创世纪到现代主义，纵向沉浸滚动，滚动条即时间轴。
- **放映厅**：带进度条与播放/暂停，可停在某一件上细看，放映员不会催场。
- **游客中心**：参观须知、版权与二创声明、投稿路径、无障碍说明、殿史纪年。
- **圣物全图鉴**：素材仓全量接入，分类与关键词双筛选。
- **友站星图**：全网奶蛙同好站点分门别类陈列，点击即出馆，本馆只负责指路。
- **背景音乐**：入殿即闻圣咏，可随时静音。肃静不是必须的，快乐才是。
- **零构建**：纯静态，`docs/index.html` 内联全部 CSS/JS，无框架、无需构建、可离线安装。

## 五、技术档案（极客向）

| 能力 | 实现 |
| --- | --- |
| 静态站点 | 核心样式/脚本内联于 `docs/index.html`，配套本地素材、PWA 图标与 Service Worker，无需构建即可部署 |
| hash 路由多视图 | `#home` / `#halls` / `#hall-N` / `#w-<编号>` / `#chronicle` / `#visit` / `#friends` / `#relics` / `#search` / `#about` |
| 纯 CSS 3D 画廊之门 | 三层视差画作 + 双开金门 + 门缝圣光，无 WebGL，显卡不参与 |
| 性能优先 | 懒加载 + LQIP 模糊占位淡入 + 解码完成淡入 + 邻近预载；`content-visibility` 降低长列表渲染成本 |
| 多端适配 | 窄屏沉浸卡片 / 宽屏版心放宽 / 异形屏安全区 / 吸顶厅导航 |
| 无障碍与降级 | 键盘全可达（作品大图 `tabindex` + Enter 打开说明牌、放映厅焦点圈闭与还原、skip-link）、路由驱动 `aria-current`、`prefers-reduced-motion` 全量降级、alt 与标题一致、加载失败兜底 |
| 路由健壮性 | 非法 `#hall-N` 回落全部展厅不白屏；`#w-` 深链兼容 `NW-` 前缀，无效编号自动复位；`document.title` 随视图同步 |
| PWA | `manifest.webmanifest` + Service Worker（外壳 network-first 离线回退 + 同源媒体 cache-first）+ 安装入口；「随缘一观」随机开馆、说明牌一键复制深链 |
| 分享与回访 | OG/Twitter 分享卡片；首页「今日圣像」按日轮换；「参观足迹」仅存本机；`<noscript>` 保障禁 JS 环境可见 |
| 数据可校验 | `scripts/export_collection.py` 校验藏品索引；素材侧由 wallpaper `assets.json` + `Assets Check` CI 保证清单与缩略图一致 |
| 现代视觉层 | View Transitions · 极光底幕 · 金色光幕 · 圣门金尘 · 首屏 Ken Burns · 玻璃导航 · 阅读进度条 · 流光标题 · Web Audio 教堂混响 · `:has()` 状态样式（全部渐进增强） |
| 自动部署 | GitHub Actions：push main → Pages 自动上线；Cloudflare Pages 提供同源镜像 |

> 目录小抄：`docs/index.html` 官网源文件 · `docs/data/collection.json` 藏品索引 · `docs/data/assets.json` 素材清单 · `docs/assets/relics/` 缩略图 · `scripts/` 校验脚本 · `palette.json` 调色板单源 · `themes/` 各平台主题 · `resources/ports.yml` 移植登记 · `site/` 旧版画廊（仅存档）
